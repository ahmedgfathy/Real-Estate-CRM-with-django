**Glomart CRM** is a comprehensive, enterprise-grade Real Estate Customer Relationship Management system designed specifically for the Egyptian real estate market. Built with **Python Django** and **SQLite/MariaDB**, it provides powerful tools for managing properties, leads, projects, and customer relationships.

## ⚡ Quick Start

<div align="center">
<img src="https://cdn.dribbble.com/users/2046015/screenshots/4596912/media/3c39a8e6ad0a3e7c9b1a4c8b8c5a9f3a.gif" width="400" style="animation: bounce 2s infinite;" alt="Quick Start">

### 📋 Prerequisites

- Python 3.10 or higher
- pip (Python package manager)
- Git

### 🚀 Installation

#### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/glomart-crm-django.git
cd glomart-crm-django
```

#### 2️⃣ Create Virtual Environment

```bash
python3 -m venv .venv
source .venv/bin/activate  # Linux/Mac
# or
.venv\Scripts\activate     # Windows
```

#### 3️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

#### 4️⃣ Configure Environment

```bash
cp .env.example .env
# Edit .env with your settings
```

#### 5️⃣ Run Migrations

```bash
python manage.py migrate
```

#### 6️⃣ Create Superuser

```bash
python manage.py createsuperuser
# Follow prompts to create admin account
```

#### 7️⃣ Initialize RBAC System

```bash
python manage.py init_rbac
python manage.py init_enhanced_rbac
```

#### 8️⃣ Run Development Server

```bash
python manage.py runserver
```

#### 9️⃣ Access the Application

```
🌐 http://127.0.0.1:8000/
👤 Username: admin
🔑 Password: (your superuser password)
```

### Permission Levels

| Level | Code | Description | Capabilities |
|-------|------|-------------|--------------|
| 🟢 1 | `view` | View Only | Read data, view lists, export |
| 🟡 2 | `edit` | Edit | View + Update records |
| 🟠 3 | `create` | Create | View + Edit + Create new records |
| 🔴 4 | `delete` | Delete | View + Edit + Create + Delete records |

### Field-Level Permissions

```python
# Example: Restrict budget field visibility
FieldPermission.objects.create(
    profile=sales_profile,
    module=leads_module,
    model_name='Lead',
    field_name='budget_max',
    can_view=True,        # Can see the field
    can_edit=False,       # Cannot modify
    can_filter=True,      # Can use for filtering
    is_visible_in_list=True,
    is_visible_in_detail=True,
    is_visible_in_forms=False  # Hide in forms
)
```

```python
    property_type = ForeignKey(PropertyType)
    category = ForeignKey(PropertyCategory)
    
    # Rooms
    rooms = IntegerField()
    bathrooms = IntegerField()
    living_rooms = IntegerField()
    
    # Pricing (multi-currency)
    total_price = DecimalField(max_digits=15)

    # Features (JSON)
    facilities = JSONField(default=list)

    security_features = JSONField(default=list)
    
    # Media (JSON)
    primary_image = TextField()           # JSON array
    images = JSONField(default=list)
    videos = JSONField(default=list)
    
    # Assignment
    handler = ForeignKey(User)
    sales_person = ForeignKey(User)
    assigned_users = ManyToManyField(User)
```

```python
class Lead(models.Model):
    # Primary Key (UUID)
    id = UUIDField(primary_key=True, default=uuid.uuid4)
    
    # Contact Info
    first_name = CharField(max_length=100)     # Required
    last_name = CharField(max_length=100)      # Required
    mobile = CharField(max_length=20)          # Required
    email = EmailField(blank=True, null=True)
    phone = CharField(max_length=20, blank=True)
    
    # Classification
    lead_type = ForeignKey(LeadType)           # Buyer, Seller, Investor
    source = ForeignKey(LeadSource)            # Website, Referral
    status = ForeignKey(LeadStatus)            # New, Contacted, etc.
    priority = ForeignKey(LeadPriority)        # High, Medium, Low
    temperature = ForeignKey(LeadTemperature)  # Hot, Warm, Cold
    
    # Property Interests
    budget_min = DecimalField()
    budget_max = DecimalField()
    preferred_locations = TextField()
    property_type = CharField()
    
    # Scoring & Assignment
    score = IntegerField(default=0)            # 0-100
    assigned_to = ForeignKey(User)
    created_by = ForeignKey(User)
    
    # Timestamps
    created_at = DateTimeField(auto_now_add=True)
    last_contacted = DateTimeField()
    next_follow_up = DateTimeField()
```

```python
    total_units = IntegerField()
    available_units = IntegerField()
    min_price = DecimalField()
    max_price = DecimalField()
    currency = ForeignKey(Currency)
    
    # Assignment
    assigned_to = ForeignKey(User)
    created_by = ForeignKey(User)
```

### Deployment Commands

```bash
# 1. Clone repository
git clone https://github.com/your-username/glomart-crm-django.git
cd glomart-crm-django

# 2. Setup virtual environment
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# 3. Configure environment
cp deployment/.env.production .env

# 4. Run migrations
python manage.py migrate

# 5. Collect static files
python manage.py collectstatic

# 6. Create superuser
python manage.py createsuperuser

# 7. Configure Gunicorn
sudo cp scripts/glomart-crm.service /etc/systemd/system/
sudo systemctl enable glomart-crm
sudo systemctl start glomart-crm

# 8. Configure Nginx
sudo cp scripts/nginx-glomart-crm.conf /etc/nginx/sites-available/
sudo ln -s /etc/nginx/sites-available/nginx-glomart-crm.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```
